# Manba

Verification tool built with FastAPI.

```bash
.venv\Scripts\activate
uvicorn app.main:app --reload
```

Docs: http://127.0.0.1:8000/docs

## Data sources

- `data/tanzil/` holds the Quran texts from the [Tanzil Project](https://tanzil.net) (Uthmani and simple-clean),
  unmodified and used under its CC BY 3.0 terms: source must be credited and linked to tanzil.net.
  Each file keeps Tanzil's original copyright header.
- `corpus.json` is generated offline from those files by `ingest_quran.py` (Uthmani as `text`, simple-clean as `match_text`,
  surah names in `data/surah_names.json`). `validate_corpus.py` checks it against Tanzil character for character.
- `corpus_hadith.json` holds the nine books of the `the_9_books` folder of
  [AhmedBaset/hadith-json](https://github.com/AhmedBaset/hadith-json) (tag v1.2.0, texts scraped from sunnah.com), Arabic only,
  40,818 hadiths: Bukhari, Muslim, Abu Dawud, Tirmidhi, Nasa'i, Ibn Majah, Muwatta Malik, Musnad Ahmad, Sunan al-Darimi.
  It is generated by `ingest_hadith.py`; the raw files are downloaded into `data/hadith/` (git-ignored) and checked against
  pinned SHA-256 values. The dataset has no license file, so check sunnah.com's terms before redistributing it.
  Coverage notes: Musnad Ahmad is incomplete in the source (1,374 hadiths, 8 chapters); 125 Muwatta hadiths have no Arabic text
  and were skipped. Where a text occurs in several books the first in the order above is reported.
  **Hadith numbers are not provided yet**: the dataset's index is a scrape sequence, not the standard numbering,
  so `source.number` is empty for hadith results.
